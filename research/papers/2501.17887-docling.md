# Docling: An Efficient Open-Source Toolkit for AI-driven Document Conversion

> Source: arXiv:2501.17887 (2025). Livathinos, Auer, Lysak, Nassar, Dolfi, … Staar (IBM Research). PDF in `pdf/2501.17887.pdf`.

## Thesis

Open-source toolkit that parses popular document formats (PDF, images, MS Office, HTML) into a unified, richly structured representation and exports to **Markdown** and JSON for generative-AI / LLM consumption. Runs on commodity hardware; Python API and CLI.

## Relevance to the book

Ch2 §"Everything Becomes Markdown": one of the tools that make the convert-everything-to-Markdown strategy practical, alongside Pandoc and Microsoft MarkItDown. Markdown as the AI-era "text stream" — the Unix "text is the universal interface" principle, made concrete.
