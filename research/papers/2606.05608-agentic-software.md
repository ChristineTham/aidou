# Agentic Software: How AI Agents Are Restructuring the Software Paradigm

> Source: arXiv:2606.05608 (4 Jun 2026). Zhenfeng Cao. PDF in `pdf/2606.05608.pdf`.

## Thesis

AI agents are not a faster way to write code but a restructuring of software itself: rather than humans authoring static code to encode decision logic, the agent *is* the software, generating code dynamically at runtime. The core unit of work shifts from authoring code to **architecting intent**; the practitioner's role moves from *code author* to *intent architect*, redefining where value is created.

## Relevance to the book

Directly supports the Ch3 argument that intent is the scarce human input and implementation is the model's job — and that the person who can articulate intent best (often the domain expert) is increasingly the one best placed to build software.
