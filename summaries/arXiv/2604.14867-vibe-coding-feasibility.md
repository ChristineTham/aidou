# Vibe-Coding: Feedback-Based Automated Verification with no Human Code Inspection, a Feasibility Study

> Source: arXiv:2604.14867 (16 Apr 2026). Michal Töpfer, František Plášil, Tomáš Bureš, Petr Hnětynka (Charles University, Prague). PDF in `../../sources/arXiv/2604.14867-vibe-coding-feasibility.pdf`.

## Thesis

Couples a vibe-coding feedback loop with automated verification: LLM-generated code for runtime-adaptive systems is iteratively refined against architectural and functional constraints formalised in a temporal logic, with no manual code review. Dragon Hunt case study: fine-grained constraint violations give actionable feedback that yields a valid adaptation manager within a few iterations, while coarse metric-based feedback often stalls.

## Key finding

The approach targets **systems designed by domain experts with no programming skills**; **feedback precision is the dominant factor** for reliable vibe coding, "obviating the need for human code inspection." Feasibility study — a frontier signal, not a general proof.

## Relevance to the book

Ch3 evidence that domain experts (not career coders) can build working software when the checks/feedback are precise — the verification-and-intent side of ICE.
