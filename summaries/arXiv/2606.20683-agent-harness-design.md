# 2606.20683 — From Question Answering to Task Completion: A Survey on Agent System and Harness Design

> Source: <https://arxiv.org/abs/2606.20683> — Guo, Jianyuan, et al. (17 authors; 2026). PDF in `../../sources/arXiv/2606.20683-agent-harness-design.pdf`.

## Thesis

A 2026 survey that reads the last few years through a **model–harness lens**: agents have progressed from answering questions to completing complex, long-horizon tasks, and the survey traces four engineering paradigms of that progression. Its central question is where agent performance actually comes from — the foundation model, the execution *harness* (tools, retries, sandbox, control flow), or the coupling between them — and it decomposes agent execution into six coupled runtime responsibilities. The conclusion: agent quality emerges from the interaction of model capability, runtime infrastructure, task structure, and evaluation, not from treating an agent as "a model with some tools bolted on."

## Relevance to the book

- **Ch1 §1.3 (From Chatbot to Agent)**: current, academic confirmation of the book's thesis that "the model is the easy part; the craft is everything you build around it."
