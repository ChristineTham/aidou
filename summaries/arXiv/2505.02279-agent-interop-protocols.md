# 2505.02279 — A Survey of Agent Interoperability Protocols: MCP, ACP, A2A, and ANP

> Source: <https://arxiv.org/abs/2505.02279> — Ehtesham, Abul, et al. (4 authors; 2025). PDF in `../../sources/arXiv/2505.02279-agent-interop-protocols.pdf`.

## Thesis

A 2025 survey of the standards that let agents connect to tools and to each other — the plumbing of the emerging agent ecosystem. It compares four: **MCP** (Anthropic, Nov 2024), a JSON-RPC client–server interface for tool and context access; **ACP** (IBM, 2025), RESTful HTTP messaging with session management; **A2A** (Google, 2025), peer-to-peer task delegation between agents via capability "agent cards"; and **ANP** (open), decentralised agent discovery using W3C DIDs. It proposes a phased roadmap — MCP for tool access, then ACP for structured messaging, then A2A for collaboration, then ANP for open marketplaces.

## Relevance to the book

- **Ch1 §1.3 (From Chatbot to Agent)**: extends the chapter's MCP paragraph into "today's diversity" — MCP was the first plug, but an ecosystem of interoperability protocols has grown up around agents, evidence that the value has moved decisively into the system around the model.
- Grounds the claim that connecting a model to tools and to other agents has become a matter of shared standards, not custom wiring.
